# Awesome Weight-Space Programming

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re) ![Last Updated](https://img.shields.io/badge/updated-2026--11--11-blue)

A curated list of papers and research resources on **Weight-Space Programming (WSP)**: using language models and executable procedures to inspect, construct, or edit neural-network weights. Special attention is given to recent preprints, capability installation, reusable weight programs, and evidence for reliable edits.

> **Scope.** Direct WSP is distinct from ordinary gradient-based fine-tuning. Neural-program compilation, hypernetworks, model editing, and weight-space learning are included in clearly labeled *related* sections, not presented as interchangeable methods.

- **[Orbit Audits](https://arxiv.org/abs/2611.05798)** `[Weight Reading]` `[Symmetry]` `[Evaluation]` Consistency Is Not Understanding: Orbit Audits for Neural Field Weight Readers (**arXiv 2026**) [[paper](https://arxiv.org/abs/2611.05798)] — Tests whether weight readers respect function-preserving parameter permutations and rescalings.
- **[Diffusion WSP Conjectures](https://arxiv.org/abs/2611.04268)** `[Weight-Space Programming]` `[Diffusion]` `[Conjecture]` Weight-Space Programming for Improving Image-Restoration Diffusion Models: Technical Conjectures and a Recursive Improvement Loop (**Conjectural arXiv Preprint 2026**) [[paper](https://arxiv.org/abs/2611.04268)] — Proposes a diagnostic and iterative editing framework for restoration diffusion models; the main claims are hypotheses, not demonstrated results.
- **[TensorMutation](https://arxiv.org/abs/2611.09650)** `[Weight-Space Learning]` `[Model Mutation]` `[Related]` TensorMutation: Learning Weight-Space Mutations of Deep Learning Models on Neural Graphs (**arXiv 2026**) [[paper](https://arxiv.org/abs/2611.09650)] — Trains a graph network to predict parameter effects of fault-informed mutations without retraining each target model.

## Contributing

Contributions are welcome. Please open an issue or pull request with:

1. The exact title, authors, first public date, and publication status (conference/journal, arXiv preprint, or technical blog).
2. A stable paper or primary-source link, plus a code link **only when verified**.
3. Two or three tags and a one-sentence description of the actual contribution.
4. An explanation of whether the work **directly programs weights** or is **related background**.

Please avoid duplicates, invented code repositories, unsupported venue claims, and treating conjectural proposals as completed empirical results.
